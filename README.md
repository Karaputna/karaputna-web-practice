# Кав'ярня з онлайн-меню

Навчальний веб-проєкт повного циклу для практики «WEB-технології та WEB-дизайн»
(варіант 3). Сайт кав'ярні з онлайн-меню та кошиком, який автоматично
підраховує суму замовлення.

> Статус: **ПР 1** — концепція, ТЗ, репозиторій. Розробку ще не розпочато.

## Стек (планований)

| Шар | Технології |
|---|---|
| Дизайн | Figma (wireframe, дизайн-система, макети) |
| Клієнт | React (Vite), React Router, CSS custom properties, Tailwind CSS |
| Сервер | Node.js, Express, JSON-файл для даних |
| Якість | Vitest, React Testing Library, Lighthouse, axe DevTools |
| Деплой | Vercel/Netlify (клієнт), Render/Railway (сервер) |

## Структура репозиторію

.

├── client/    React-застосунок
